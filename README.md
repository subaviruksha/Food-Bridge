# FoodBridge

React + Vite + Tailwind v4 + React Three Fiber homepage for the OSCode AI Prompt Battle.

## Run
    npm install
    npm run dev

## Deploy (Vercel)
Push to GitHub, import the repo on vercel.com. Framework: Vite. Build: `npm run build`, output: `dist`.
